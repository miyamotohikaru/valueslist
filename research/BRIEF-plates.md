# 版下（図版）の描き方 — 第2次追加分

`src/components/print/plates*.ts` と同じ作りで、担当ぶんの版下を描く。

## 仕組み

1. ここで描くのは **灰色の絵（版下）**。白い紙に黒〜灰で描く。網のことは考えない
2. あとで `screen.ts` が濃さを読んで **網**（網点／線網／点刻／等高／反転の5種）にかける
3. 札の図版枠は 257×178px。**版下の 300×300 が 178×178 に縮んで真ん中に置かれる**

```ts
import type { Draw } from "./draw";

/** NO.049 科挙｡◯◯ */
const keju: Draw = (g, s) => {
  const u = s / 300;
  g.save();
  g.scale(u, u);
  // …300四方で描く…
  g.restore();
};
```

## 鉄則（守らないと必ず読めなくなる）

網は濃さを点と線の粗密に置きかえるだけの仕組み。だから：

- **大きな塊で描く。** 中間の灰色が広い面積に散らばると、ただのノイズになる
- **白ではっきり切る。** 隣り合う黒どうしは白い線・白い間を入れて離す
- **暗い面は画面の半分未満。** 真っ黒が広いとベタで潰れる
- **細かい部品を並べない。** 算盤の珠20個、花7輪のようなものは必ず読めなくなる
- **濃淡は面の中でつける。** グラデーションで立体を出すと、網にかけたとき刷り物の肌になる
- 178px に縮んだときに、**何が描いてあるか3秒でわかる**こと。輪郭がすべて

## 選ぶもの

- **ひとつの物**を大きく描く。場面や人物の群れは描かない
- その価値観を **一目で指す道具・しるし** を選ぶ（例：仇討ち＝抜き身の打刀、時間厳守＝懐中時計）
- 人の姿は避ける。**特定の民族・宗教の戯画にならないように。** 道具・文字・器物・建物の一部で指す
- 既存48枚と同じ物を使わない（刀・巻物・扇・急須・家紋・提灯・蝋燭・縄・鍬・金継ぎ・手紙・
  懐中時計・巣・暖簾・椿・鯉のぼり ほか。`plates*.ts` を見て確認すること）

## 出力

- 自分のファイルだけを作る（下で指定する）。**ほかのファイルは触らない。** git 操作もしない
- 末尾に `export const PLATES_X: Record<string, Draw> = { "049": keju, … };`
- `npx tsc --noEmit` が通ること
- 日本語のコメントを付ける（何をどう描いたか、どこを白で切ったか）
