## 今回足すもの（依頼）

1. **いまの時代から考えるとありえない過去の価値観**（日本）
   「昔はこれが当たり前だった」と聞いて今の人が驚くもの。
   法令・制度・統計で「いつ始まっていつ終わったか」が言えるものに限る。
2. **世界の代表的な価値観**（日本中心に、世界も並べる）
   条件は「**いま消えた／変わったもの**」。現役のものではなく、
   法や制度の日付で「終わった／変わった」と言えるもの。
   **地域は満遍なく。** 東アジア・南アジア・中東・ヨーロッパ・北米・中南米・
   アフリカ・オセアニア／太平洋 から偏りなく拾う。

## 棚（グループ）は日本と世界で揃える

世界のものも、**日本と同じ時代の棚**に入れる。棚は成立した時期で決まる。

| 棚 | 名前 | 入るもの |
|---|---|---|
| 1 | 前近代成立・失効 | 〜19世紀前半に成立し、法令の日付で失効したもの |
| 2 | 近代（明治相当＝19世紀後半〜1945）成立 | 近代国家・近代法とともに成立したもの |
| 3 | 戦後成立・下落（1945〜1990） | 戦後に標準装備になり、その後下がったもの |
| 4 | 現役・上昇（1990〜） | 成立年が日付まで特定できる新しいもの |
| meta | 偽史 | 「古い伝統」として近代に作られた、本物の偽物 |

## 出力

`research/round2/<担当名>.json` に JSON 配列で1ファイル。
スキーマは BRIEF.md のものに、次の2つを足す。

```json
  "country": "中国",           // 国・地域の名（絞り込みの欄に出る。日本のものは "日本"）
  "country_en": "China",
  "region": "東アジア",         // 東アジア｜南アジア｜中東｜ヨーロッパ｜北米｜中南米｜アフリカ｜オセアニア｜日本
```

## 守ること

- **一次資料に当てる。** 法令は公布日・法令番号、統計は調査名と年。
  Wikipedia は入口。最後は原典（官報・立法текст・統計表・学術書）に当てる。
- **裏が取れないものは `verdict: "drop"` にして、なぜ落としたかを書く。**
  推測で年号を埋めない。俗説（初夜権、江戸しぐさの類）は偽史として扱うか落とす。
- 1件につき `keyfacts` を4件以上。すべて出典つき。
- `hitokoto` は40字以内。`body_ja` は3段落（各120〜200字）。
- 重い題材（奴隷制・FGM・虐殺など）は、**制度と日付の話として書く。**
  煽らない。被害を軽く扱わない。今の特定の集団を貶める書き方をしない。
- 調べた結果は drop も含めて全部書く。採否は最後にこちらで決める。
