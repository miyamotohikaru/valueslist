# 価値観一覧図鑑 — 裏取りリサーチ共通ブリーフ

## 企画の背景（これを理解した上で調べること）
「価値観一覧図鑑」は、日本の価値観（規範・人生観・判断基準）を「商品」に見立て、
製造年（普及しはじめた時期）・廃番年（制度的に終わった時期）・再入荷（別の名前で復活した時期）を
一次資料で特定して並べるサイト。同シリーズに「消滅職業図鑑」「診断名アーカイブ」がある。
コンセプトは「伝統に見えて実は新しい（製造年がある）」「新品に見えて中世の在庫の再出荷」というFLIP。

証拠のタイプは2種:
- **law型（法令・初出型）**: 禁止令の日付、翻訳語の初出年、制度の廃止年という「点」で語る。
- **curve型（カーブ型）**: 世論調査の賛成率・統計の推移という「線」で語る。実データ点が必須。

## あなたの仕事
担当項目それぞれについて、Web検索・一次資料の確認で **真偽を検証** し、下のJSONスキーマで出力する。
**叩き台に書いてあることを鵜呑みにしない。** 年号・法令名・人名・書名は必ず確認し、
誤りは `draft_corrections` に明記する。確認できないものは「確認できない」と書く（推測で埋めない）。

優先する出典: 法令（太政官布告・法律番号・公布日）、官公庁統計（内閣府世論調査、国立社会保障・人口問題研究所、総務省統計局、厚労省）、
国会会議録検索システム（https://kokkai.ndl.go.jp/ API: https://kokkai.ndl.go.jp/api/1.0/speech?any=語&from=YYYY-01-01&until=YYYY-12-31&maximumRecords=1 で年別ヒット数が取れる）、
新語・流行語大賞の公式記録（自由国民社）、三省堂「今年の新語」、岩波新書・学術書（柳父章『翻訳語成立事情』、安丸良夫『日本の近代化と民衆思想』、
橋本毅彦・栗山茂久『遅刻の誕生』、牟田和恵『戦略としての家族』、竹内洋『立身出世主義』、大日向雅美『母性愛神話の罠』、赤川学『セクシュアリティの歴史社会学』、
阿部謹也『「世間」とは何か』、原田実『江戸しぐさの正体』、ホブズボウム『創られた伝統』 など）。
Wikipedia は入口として使ってよいが、**最終的な根拠は一次資料か学術書に当てる**。

## 出力（1項目ごとに1オブジェクト。JSON配列で1ファイル）
```json
{
  "draft_no": 1,
  "name_ja": "仇討ち",
  "reading": "かたきうち",
  "name_en": "Vendetta",
  "category": "規範 | 人生観 | 判断基準",
  "shelf": 1,
  "evidence_type": "law | curve",
  "made": {"label": "中世〜近世", "year": 1600, "approx": true, "fact": "…何をもって『普及』とするかの根拠…", "source": "…"},
  "discontinued": {"label": "1873 復讐禁止令", "year": 1873, "approx": false, "fact": "1873年2月7日 太政官布告第37号「復讐ヲ厳禁ス」", "source": "…"} ,
  "restocked": {"label": "2021 親ガチャ", "year": 2021, "as": "親ガチャ", "fact": "…", "source": "…"},
  "trend": "up | steady | down | discontinued | restocked",
  "keyfacts": [
    {"text": "検証済みの事実を1文で。年月日・固有名詞を含める", "source": "URLか書誌"}
  ],
  "curve": {
    "title": "「夫は外で働き、妻は家庭を守るべき」賛成率（賛成＋どちらかといえば賛成）",
    "unit": "%",
    "source": "内閣府「男女共同参画社会に関する世論調査」各年",
    "points": [[1979, 72.5], [1992, 60.1]]
  },
  "lineage": {"from": "生まれで決まる", "to": "親ガチャ", "note": "…"},
  "draft_corrections": ["叩き台の『…』は誤り。正しくは…（出典）"],
  "confidence": "A | B | C",
  "verdict": "include | drop",
  "verdict_reason": "…",
  "hitokoto": "40字以内の一文（下記の文体）",
  "body_ja": ["段落1（120〜200字）", "段落2", "段落3"],
  "sources": ["…"]
}
```
- `made`/`discontinued`/`restocked` は該当なしなら `null`。
- `confidence`: A=公文書・統計で年月日まで特定できる／B=学術書レベルで裏付けあり／C=通説・推測の域。
- `verdict`: 証拠がCで叩き台の主張を支えられないなら `drop`。ただし drop でも調べた結果は全部書く（最終判断は編集側でする）。
- `curve` は curve型のみ。**実際に取得できた数値だけ**を入れる。取れなかったら null にして `verdict_reason` に書く。
- `keyfacts` は3〜6個。すべて出典付き。

## 文体（hitokoto / body_ja）
- 常体（だ・である）。淡々と、しかし切れ味よく。感嘆符なし。
- 断定できることだけ断定する。解釈は「〜と論じられている（誰が）」の形にする。
- 参考トーン（消滅職業図鑑）: 「電子計算機がない時代、天文台・軍・研究所には『計算室』という部屋があり、数十人の計算手が机を並べて対数表や弾道表をつくりつづけていた。」
- 図鑑のメタファ（商品／製造／廃番／再入荷／在庫）は body の中で1回までなら使ってよい。多用しない。
- hitokoto は「事実そのものが驚きになる」一文。例: 「美徳が犯罪に変わった日付が、公文書で特定できる。」

## 除外ルール（企画側の決定）
- 穢れ・身分差別（部落差別に直結する内容）は扱わない。「生まれで決まる」は士農工商の身分制一般として記述し、解放令（1871）は触れてよいが、被差別身分の具体名や差別の内容は書かない。
- 夜這い等の性風俗慣行は、純潔規範の背景として1文触れるにとどめる（単独項目にしない）。

## 出力ファイル
指定されたパスにJSON配列を書く。最後に、担当項目の一覧（name_ja / confidence / verdict / 一番大事な訂正）をmarkdownの表で報告する。
